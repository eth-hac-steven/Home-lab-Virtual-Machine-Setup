# CONTRIBUTING

Thanks for wanting to help improve this repo! A few guidelines for contributors, especially beginners:

- How to propose a change
  1. Fork the repository and create a feature branch.
  2. Make small, focused changes to one README or image at a time.
  3. Commit with a clear, short message and open a Pull Request describing why the change helps beginners.

- Screenshots and images
  - Place images inside the `images/` folder of the VM guide you are editing.
  - Prefer PNG or JPG under 500 KB for faster loading. Name images using lowercase-hyphen (e.g., `vm-name.png`).

- Style
  - Use clear, numbered steps for actions (1., 2., 3.).
  - Avoid jargon or explain it briefly (one-sentence definition).

- Questions
  - If you are unsure about technical correctness, open an Issue with the text you want to change and request review.
