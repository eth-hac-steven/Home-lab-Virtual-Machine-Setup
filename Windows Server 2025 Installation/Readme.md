# Windows Server 2025 Installation

## Description

Windows Server 2025 is an important part of this home lab. It helps simulate an enterprise environment, and Active Directory is one of the many features you can install and test on this server.

## Requirements

- [Windows Server 2025 ISO](https://www.microsoft.com/en-us/evalcenter/download-windows-server-2025)

## Installation

1. Launch VirtualBox.
2. Click New.

![Launch VirtualBox](/windows%2011%20client%20pc%20Installation/images/launch-virtual-box.png)

### Virtual Machine Name and OS

- Enter a name for the virtual machine, for example Win-Serv-2025.
- Leave the VM folder at the default setting.
- Select the Windows Server 2025 ISO you downloaded.
- Leave unattended install unchecked unless you specifically want it enabled.

![VM name](/Windows%20Server%202025%20Installation/images/win-server-vm-name.png)

### Specify Virtual Hardware

- Set the base memory (RAM) to 6 GB.
- Set the CPU to 2 cores.


![Starting the machine](/Windows%20Server%202025%20Installation/images/win-server-ram.png)

### Specify Virtual Hard Disk

- Set the disk size to 80 GB or more.

![VM name](/Windows%20Server%202025%20Installation/images/win-server-storage.png)

- Click Finish. You should see the VM in the VirtualBox manager.
- Click Start.

- While the machine is starting, pay attention and press any key to boot from the CD/DVD.

- which should bring you to this page
### Selecting Language 
- Choose your language
![language-setting](/Windows%20Server%202025%20Installation/images/win-srv-lang-setting.png)

- click Next 

### Selecting A keyboard
- choose your keyboard setting 
![Selecting A keyboard](/Windows%20Server%202025%20Installation/images/win-srv-key-board-setting.png)

- click Next

### Selecting Image
![Selecting An Image](/Windows%20Server%202025%20Installation/images/selecting-img(for%20the%20Desktop%20ui).png)

- click Next

### Terms and Conditions

![Terms and conditions](/Windows%20Server%202025%20Installation/images/Terms-and-cond-click-accept.png)

### Selecting a Location to install Windows

![Selecting a Location to install Windows](/Windows%20Server%202025%20Installation/images/select-location-to%20-install-windows-server.png)

- Select which disk you want to install in on, if you have more than one
